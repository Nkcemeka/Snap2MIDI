Reading the tables

Six piano transcription models (OAF, OAFv2, HPP, Kong, TK, hFT) are scored with mir_eval. Every number is a mean over pieces, in percent; n is the number of pieces behind a row. The paper reports the onset metric; the tabs above each table switch to the others.

  • Offsets on guitar. A plucked string decays without a damping event, so a guitar note's offset is a convention of the annotator, and the guitar sets use different conventions. The onset + offset numbers on guitar are given for completeness and should be read with that in mind.
  • Velocity. The guitar sets carry no meaningful velocity annotation, so the velocity metric is reported on the piano sets only.
  • Frame. Frame scores come from each model's own evaluation code, which does not build the frame-level estimate in the same way for every model (from the frame output directly, or from the decoded notes). Compare frame numbers down a column, not across models.
